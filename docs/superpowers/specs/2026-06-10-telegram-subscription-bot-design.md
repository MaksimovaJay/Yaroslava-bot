# Telegram Subscription Bot — Design Spec
**Date:** 2026-06-10  
**Project:** Бот для платного Telegram-канала (онлайн-журнал Ярославы)

---

## Overview

Telegram-бот для управления платным закрытым каналом. Пользователь подаёт заявку на вступление → бот предлагает оплатить подписку → после оплаты одобряет заявку. Подписка автоматически продлевается каждый месяц или два.

---

## Тарифы

| Тариф | Цена | Срок |
|-------|------|------|
| Месячный | 500 ₽ | 30 дней |
| Двухмесячный | 900 ₽ | 60 дней |

---

## Стек

- **Язык:** Python 3.11+
- **Фреймворк бота:** aiogram 3.x
- **База данных:** SQLite + aiosqlite
- **Планировщик:** APScheduler (ежедневная проверка подписок)
- **Платёжный модуль:** заглушка сейчас → ЮKassa позже (через абстрактный интерфейс)
- **Хостинг:** VPS Beget, 1 ядро / 1 ГБ RAM / 10 ГБ NVMe, Ubuntu 24.04, 480 ₽/мес
- **Режим работы бота:** long polling (проще деплоить на VPS, чем вебхуки)

## Пользовательский сценарий

```
Пользователь нажимает ссылку на канал
        ↓
Telegram: "Подать заявку на вступление"
        ↓
Бот получает ChatJoinRequest
        ↓
[Пользователь заблокирован?] → ДА → игнорировать
        ↓ НЕТ
[Есть активная подписка?] → ДА → сразу одобрить заявку
        ↓ НЕТ
Бот пишет в личку: выбери тариф
  [💳 1 месяц — 500 ₽] [💳 2 месяца — 900 ₽]
        ↓
Пользователь выбирает тариф
        ↓
Бот проводит оплату (заглушка / ЮKassa)
        ↓
[Оплата прошла?] → НЕТ → сообщение об ошибке, предложить попробовать снова
        ↓ ДА
Создать запись в subscriptions
Одобрить ChatJoinRequest (бот должен быть админом канала)
Отправить пользователю: "Добро пожаловать! Подписка активна до [дата]"
```

## Автопродление (ежедневный планировщик, 10:00)

```
Найти все подписки где expires_at <= сегодня + 3 дня
        ↓
За 3 дня до истечения → напомнить пользователю в личку

Найти все подписки где expires_at <= сегодня
        ↓
Попытка автосписания (заглушка: успех / ЮKassa: API-запрос)
        ↓
[Успех?] → ДА → обновить expires_at, сообщить пользователю
        ↓ НЕТ
Дать 3 дня льготного периода (пользователь остаётся в канале), отправить ссылку на ручную оплату
        ↓
Если через 3 дня всё ещё не оплачено:
  Кик из канала (banChatMember + unbanChatMember)
  Установить status = "expired"
  Сообщить пользователю что доступ закрыт
```

**Кик из канала:** Telegram не имеет метода "просто удалить" — используем `banChatMember` + немедленно `unbanChatMember`. Пользователь вылетает, но может подать заявку снова.

---

## Повторная подписка после кика

Пользователь снова нажимает ссылку на канал → подаёт заявку → бот видит нет активной подписки → снова показывает выбор тарифа → платит → попадает обратно. Полностью автоматически, без участия администратора.

## Админ-панель (только в Telegram)

Команда `/admin` (только для ADMIN_ID из конфига) → inline-меню:

```
📊 Статистика    👥 Подписчики
🚫 Заблокировать  ➕ Добавить вручную
```

**Статистика:**
- Активных подписчиков: N
- Выручка за текущий месяц: N ₽
- Истекает в ближайшие 3 дня: N человек

**Подписчики:**
- Список: имя, @username, тариф, дата окончания
- Пагинация по 10 записей

**Заблокировать:**
- Ввести Telegram ID или переслать сообщение пользователя
- Бот кикает из канала и ставит is_banned = true
- Повторные заявки от забаненного игнорируются

**Добавить вручную:**
- Ввести Telegram ID
- Выбрать тариф и срок
- Бот создаёт подписку и отправляет пользователю одноразовую инвайт-ссылку в личку (через `createChatInviteLink`)

## Настройка канала (разовая, вручную)

1. Бот должен быть **администратором канала** с правом "Добавление участников"
2. В настройках канала включить **"Заявки на вступление"** (не прямое добавление)
3. В `config.py` прописать `CHANNEL_ID` — числовой ID канала (например `-1001234567890`)

## Деплой на VPS Beget

1. Установить Python 3.11, создать venv
2. Скопировать код, создать `.env` с токенами
3. Запустить через `systemd` — бот будет автоматически стартовать при перезагрузке сервера
